Spot the female where the column usually says F. The data is messy on purpose, as below.
Deliberately messyclean it before you count it
  • sex holds F, M, female, Male, f, X, U and NULL
  • Diagnosis codes like J189, j18.9 and J18.9  instead of J18.9
  • Missed appointments recorded as both DNA and Did not attend, in mixed casing
  • About 1.5% of patients registered twice under a second MRN
  • A legacy text date column that's mostly dd/mm/yyyy, but not always
  • Appointments imported twice, and a few discharges keyed before their admission

On the Mac · Claude Code
Set it up
Clones the repo and runs SQL Server 2022 in Docker with the data loaded.
Clone https://github.com/sh4unn/sql-practice into ~/github/sql-practice (or git pull if it's already there). Start Docker with `colima start`, then run ./setup_sqlserver.sh to load the SqlPractice database into SQL Server 2022, and ./practice/run_answers.sh to check all 15 answers still run. Then tell me how to connect from DBeaver. The sa password is in .env: don't print it.
At work · SSMS or Azure Data Studio
Load it
Needs a SQL Server where you can create a database. It takes about a minute.
1. Download sql-practice-tsql.zip:
   https://github.com/sh4unn/sql-practice/releases/latest/download/sql-practice-tsql.zip
2. Unzip it, open 01_create_schema.sql and run it (F5).
3. Open 02_load_data.sql and run it.
4. Query the new SqlPractice database, e.g.
   SELECT TOP (10) * FROM dbo.admission;
